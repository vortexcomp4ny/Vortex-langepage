# Vortex Landing Page

Base em React + Vite + Tailwind CSS para a landing page da Vortex, agencia focada em trafego pago, landing pages de alta conversao e e-commerce.

## Rodar localmente

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev`: inicia o servidor Vite
- `npm run build`: gera a build de producao
- `npm run lint`: roda ESLint
